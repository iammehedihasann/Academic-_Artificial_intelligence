# 📝 To-Do List App (Python + Tkinter)

A simple and elegant **To-Do List desktop application** built with **Python’s Tkinter GUI library**.  
This app helps you organize your daily tasks — you can easily **add, delete, mark as complete**, or **clear** them, all through a clean and user-friendly interface.

---

## 🚀 Features

✅ **Add Tasks** — Add new tasks easily using the input box.  
✅ **Delete Tasks** — Remove selected tasks from the list.  
✅ **Mark Complete** — Mark selected tasks as completed (✓ and gray text).  
✅ **Clear All Tasks** — Delete all tasks in one click.  
✅ **Scroll Support** — Scroll through your list when it gets long.  
✅ **Responsive UI** — Clean design with modern colors and layout.

---

## 🧰 Technologies Used

- **Python 3.x**
- **Tkinter** — Python’s standard GUI library

## 💡 How to Use the App

1. **Add a Task** — Type a task in the input box and click **“Add Task”**.  
2. **Mark Complete** — Select a task and click **“✓ Mark Complete”** to mark it as done.  
3. **Delete Task** — Select a task and click **“✕ Delete Task”** to remove it.  
4. **Clear All** — Click **“Clear All”** to remove all tasks from the list.  
5. **Enjoy** — Your tasks stay visible in an easy, scrollable list with a modern, user-friendly interface.
